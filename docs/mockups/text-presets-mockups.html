Preset text messages that fill in the seller's first name + street

Three ways to put presets on the Lead page and the Today card. All three share the same plumbing: a saved list of templates with tokens — {{first_name}} · {{street}} (e.g. “Maple Ave”) · {{address}} (“412 Maple Ave”) · {{my_name}} — rendered from the lead the moment you pick one. The rep always sees the filled-in text before it goes out; a token the lead can't fill (no first name on file) is highlighted amber instead of silently sending “Hi ,”. Same tokens the buyer bulk-texter already uses.

How they compare

A · Chips in composer

  • Fewest new parts — one chips row, reused in 3 places
  • Rep always lands in the editor before sending
  • Still 3 clicks from the Today card (💬 → chip → Send)

B · Preview menu

  • Read the filled-in text before opening anything
  • Keyboard 1–5 for speed on the board
  • Header Text button gains a ▾; menu can get long past ~6 presets

C · Strip + feed block

  • Fastest: tap → Send, never leaves the board
  • Matches the Follow-up strip + Quick comments the reps already know
  • Adds height to every card; preview needs room on a 390px phone

Under the hood (all three): presets stored as one JSON list (Frappe default, no new doctype — same trick as Lead Assignment rules); {{street}} = property address with the house number stripped, {{address}} = full street line; the send still goes through the existing send-text path so it lands on the lead's timeline like any other text. Bulk-texting buyers keeps its own per-message confirm.
